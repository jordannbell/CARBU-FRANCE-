# CARBU-FRANCE-
 Carbu France est une application mobile qui aide les automobilistes à trouver le carburant le moins cher dans leur zone. ▎ ▎ Elle s'appuie sur les données ouvertes du Ministère de l'Économie et des Finances (prix des carburants en France) et affiche les stations sur une carte, avec le prix et l'enseigne de chacune.
