# Politique de sécurité

## Signaler une vulnérabilité

N'ouvrez pas de ticket public. Écrivez à l'auteur du dépôt (contact sur son profil GitHub) avec :
une description, les étapes de reproduction, l'impact estimé. Une réponse est visée sous 7 jours.

## Périmètre

- `backend/` : API et ingestion.
- `mobile/` : application Expo / React Native.

## Mesures en place

Voir `docs/04-securite-architecture.md` : modèle de menaces, contrôles, risques résiduels et liste de contrôle pour la production.

## Versions prises en charge

Seule la branche `main` reçoit des correctifs.
